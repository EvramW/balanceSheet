# 📊 Advanced Financial Statements Analysis System

An interactive, professional financial analysis web application built with **Streamlit**. This system automates the processing of financial statement Excel sheets, calculates over 20 critical financial metrics, generates advanced interactive visualizations, and compiles strategic recommendations.

---

## ✨ Features

- **📂 Seamless Excel Upload:** Upload financial statements with unstructured time periods (Months/Quarters/Years).
- **💧 Liquidity Analysis:** Calculates Current Ratio, Quick Ratio, Cash Ratio, and Working Capital.
- **🏗️ Capital Structure & Leverage:** Analyzes Debt Ratio, Equity Ratio, and Debt-to-Equity structures.
- **💰 Profitability Tracking:** Monitors Return on Equity (ROE), Return on Assets (ROA), and Net Profit Margins.
- **🔄 Activity & Efficiency Operations:** Tracks Inventory Turnover, Receivables Turnover, and Cash Conversion Cycles.
- **📈 Advanced Visualizations:** - Dynamic multi-panel timelines for macro trends.
  - Radar charts comparing baseline vs. latest period performances.
  - Percentage change bar charts mapping directional asset and profit shifts.
- **🔍 Granular Deep Dives:** Dedicated panel for isolated periodic examination with dynamically generated mathematical proofs (`Numerator ÷ Denominator`).
- **🖨️ Print-Ready Reports:** Tailored Print CSS that hides interactive elements (sidebars, uploaders, tabs) automatically when printing to PDF (`Ctrl+P` / `Cmd+P`).
- **🌐 Full Right-To-Left (RTL) Support:** Native Arabic text reshaping and layout orientation optimization.
